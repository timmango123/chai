## 二、瀏覽器實測（Render）

- 開場：長段歡迎文字已拿掉；第一則訊息就是心情問題；角色說明預設隱藏；頂端沒有一鍵隱藏。
- 四種主題下心情按鈕都看得到字（靜謐星空：淺字配深底）。
- 「生氣 4」→ 籃球隊被罵：AI 先問以前有沒有被當眾罵過，接著提到「想先怎麼處理」；回答「還不知道」後，給出兩個方向讓學生選；第三輪提議對話中檢核；六題逐題點選後，出現白話結果和字條。
- 輕微霸凌：第一句沒有卡片，第二句（「今天又在笑我」）出現卡片，頂端的轉介單按鈕也出現。
- 紅燈：四個按鈕都在；自傷情境不顯示 113；面板高度符合視窗；「我需要幫助」「找真人聊聊」（生命線 LINE 時段判斷）「幫我整理狀況」（小卡顯示在面板內）都正常。在網頁裡直接送紅燈訊息，5.3 秒得到 AI 回覆（之前看到的長時間等待，是測試瀏覽器隱藏時被暫停，不是網站慢）。
- 一鍵隱藏（面板內與右側卡片）、笑話、背景音樂開關都正常；手機寬度 375 沒有橫向捲動。

## 三、這次修正（v2.11.1）

1. 霸凌第二次提到時換了說法：補上「又在笑我」「被取笑」「笑我胖」；家人笑我，而且沒有提到同學、學長姊等同儕時，不算校園霸凌。
2. 學生被問打算後說「不知道」：新增 `suggest_after_unknown`，先接住，再給一兩個小方法，並說可以找輔導老師或信任的大人；只給一次，之後不再推。
3. 「打算怎麼處理」這一輪規定 AI 一定要用問句問出來。
4. 隱私、身分、界線、「不知道」這幾種回覆，AI 的版本被安全檢查擋下時，改送審過的固定文字，不再顯示「沒辦法回覆」。

## 四、第二輪（Render v2.11.1，87 個情境 × 2，共 350 則）

| 項目 | 結果 |

| 回覆時間 | 中位數 3.8 秒，最長 12.3 秒；連線錯誤 0 |
| 輕微霸凌換說法 | 10 段第二次都出現卡片（第一輪有 2 段沒有） |
| 明確霸凌、性平、誇飾、紅燈重開、鄉鎮資源、記憶、角色、注入、其他 API | 兩次都和第一輪一樣正常；「埔里國中」26 次都查得到 |
| 預期不符 | 只有「大家的負擔」「不想回家」兩句，都是第一輪就記錄的「先確認、第二輪才升級」設計；腳本預期已改成兩輪判斷 |
| 一般回覆兩個問句 | 6 / 350，仍只記錄 |
| **分支 B** | 以前的經驗 21 / 24 段有問；**打算只有 12 / 24 段問出來**；「不知道」後給小方法 17 / 40 次 |

分支 B 的原因：真實 AI 每輪都用問句結尾，「連續兩輪發問後休息一輪」的規則把「打算怎麼處理」這一輪的問題取消了，系統也就記成「還沒問」，後面的「不知道」就接不到小方法。本機測試用的替身回覆沒有問號，所以第一輪修正時沒測到。

**v2.11.2 修正**：學生剛回答完以前的經驗時，打算的問題照問；學生沒回答時休息規則不變（原有兩個測試仍通過）。另外「心裡空空的」「一直想哭」等算感受。新增測試用帶問號的回覆重現這個情況。本機重現：老師罵、跟媽媽吵架、分手三段都變成「以前的經驗 → 打算 → 不知道後給小方法」。
